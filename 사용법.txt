==================================================
  Gen Z Lab. 뽑기판 사용법
==================================================

■ 실행하기
  1. "Gen Z Lab. 뽑기판.exe" 를 더블클릭합니다. (설치·인터넷 필요 없음)
  2. 처음 실행할 때 "Windows의 PC 보호" 경고가 뜨면
     [추가 정보] → [실행] 을 누릅니다.
  3. 엔터 쿠션 버튼은 USB에 꽂기만 하면 됩니다. (키보드 엔터와 같습니다)


■ 뽑기 진행 (참여자)
  - 엔터 버튼을 한 번 누르면 불빛이 돌다가 알아서 멈춥니다.
  - 멈춘 칸에서 종이가 빠져나와 펼쳐지고, 결과 화면이 나옵니다.
  - 결과 화면에서 엔터를 누르거나 8초 기다리면 다음 사람 차례입니다.
  - 스페이스 키도 엔터와 똑같이 동작합니다.


■ 키 모음
  엔터 / 스페이스 : 뽑기 진행
  F2              : 관리자 모드(설정) 열기 / 닫기
  F11             : 전체 화면 켜기 / 끄기
  Esc             : 관리자 모드 닫기

  ※ 마우스를 움직이면 화면 오른쪽 위에 [설정 (F2)] [전체 화면] 버튼이
     3초 동안 나타납니다. 키 대신 이 버튼을 눌러도 됩니다.


■ 관리자 모드 (F2)
  F2 를 누르면 설정 화면이 열립니다. 바꾼 내용은 바로 저장되고
  뽑기판에 바로 반영됩니다. 다시 F2 를 누르면 뽑기판으로 돌아갑니다.

  [상품]
    - 상품명, 수량, 색상, 상품 이미지, 효과음을 고칩니다.
    - [+ 상품 추가] 로 늘리고, ✕ 로 지우고, ▲▼ 로 순서를 바꿉니다.
    - 상품 이미지를 넣으면 그 상품이 뽑혔을 때 결과 화면에
      캐릭터 대신 그 이미지가 나옵니다.
    - 맨 아래 줄(꽝 또는 마지막 상품)은 남는 칸을 자동으로 채웁니다.

  [판 · 연출]
    - 총 칸 수        : 100 / 120 / 150 / 200 / 직접 입력
    - 꽝              : 꽝 있음 / 전원 당첨
    - 화면 방향       : 자동 / 가로 TV / 세로 TV
    - 전체 화면       : 전체 화면 / 창 모드
    - 불빛 이동·속도  : 무작위 또는 순서대로, 빠르기 1~10단계
    - 진행 방식       : 아래 세 가지 중에서 고릅니다.
        · 알아서 멈춤 : 엔터를 한 번 누르면 불빛이 돌다가 알아서 멈춥니다. (기본)
        · 눌러서 멈춤 : 엔터를 누르면 돌고, 한 번 더 누르면 멈춥니다.
        · 계속 돌기   : 불빛이 항상 돌고 있습니다. 엔터를 누르면 그 자리에
                        바로 멈추고 상품이 열리며, 결과가 끝나면 다시 돕니다.
    - 도는 시간       : "알아서 멈춤"에서 불빛이 도는 시간 (기본 1초)
    - 멈추는 시간     : 0초면 바로 멈춤, 늘리면 점점 느려지다 멈춤
    - 종이 보여주는 시간 : 펼쳐진 종이를 보여주는 시간 (기본 1초)
    - 결과 유지 시간  : 결과 화면이 떠 있는 시간 (기본 8초, 0은 수동)
    - 음량

    ※ 뽑기가 너무 빨리 끝나면 "도는 시간", "멈추는 시간",
       "종이 보여주는 시간" 을 늘리면 됩니다.

  [문구]
    - 판 위 안내, 버튼 글자, 캐릭터 말풍선, 당첨·꽝 문구를 바꿉니다.

  [꾸미기]
    - 배경 이미지, 로고 이미지를 바꿉니다.
    - 로고·캐릭터·열쇠·칸 번호를 보이거나 숨깁니다.
    - 칸 색상, 강조 색상을 바꿉니다.

  [운영]
    - 마지막 뽑기 되돌리기 : 실수로 뽑았을 때 한 번 되돌립니다.
    - 뽑기 기록 내보내기   : 시간·칸 번호·상품을 엑셀용 파일(CSV)로 저장합니다.
    - 설정 내보내기 / 불러오기 : 설정을 파일로 저장하거나 다른 PC로 옮깁니다.
    - 새 판 만들기         : 상품을 다시 섞어 처음부터 시작합니다.
                             (지금 판의 기록은 지워지니 먼저 내보내세요)
    - 프로그램 종료

  [기본 정보]
    - 화면 제목, 행사 이름을 바꿉니다.
    - 관리자 비밀번호를 정하면 F2 를 눌렀을 때 비밀번호를 묻습니다.


■ 행사 전 준비 순서
  1. F2 → [상품] 에서 실제 상품명과 수량을 입력합니다.
  2. [판 · 연출] 에서 칸 수와 꽝 여부를 정합니다.
  3. [운영] → [새 판 만들기] 를 눌러 깨끗한 판으로 시작합니다.
  4. F11 로 전체 화면을 켭니다.
  5. 엔터 버튼으로 한두 번 뽑아 보고, [새 판 만들기] 로 다시 초기화합니다.


■ 알아두면 좋은 점
  - 뽑을 때마다 자동 저장됩니다. 프로그램이나 PC가 꺼져도
    다시 켜면 뽑던 판이 그대로 이어집니다.
  - 판을 다 뽑으면 "모든 칸을 뽑았어요" 화면이 나옵니다.
    F2 → [새 판 만들기] 로 새로 시작하세요.
  - 설정과 뽑기 상태는 PC마다 따로 저장됩니다. 다른 PC에서 같은 설정을
    쓰려면 [설정 내보내기] 로 만든 파일을 함께 가져가서
    [설정 불러오기] 를 하세요. (상품 이미지는 다시 골라야 합니다)
  - 칸이 200개면 뜯긴 칸의 상품명이 작게 보입니다.
    상품명이 길면 100~120칸을 권장합니다.
  - 관리자 화면의 확인 창은 마우스로만 눌립니다.
    (엔터 버튼을 연타해도 실수로 지워지지 않습니다)
